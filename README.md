# CamSync

CamSyncは、防犯カメラの映像に表示されている時刻と端末時刻を比較し、カメラ時計の進み・遅れを秒単位で計算・記録するモバイル向けPWAです。

バックエンド、アカウント、クラウドデータベース、分析サービス、外部ライブラリを使用しない静的Webアプリです。記録はブラウザのIndexedDBに保存され、保存内容を外部へ送信する処理はありません。

**アプリを開く:** [https://yucchiz.github.io/camsync/](https://yucchiz.github.io/camsync/)

## 主な機能

- 端末の現在時刻を固定し、防犯カメラの表示時刻との差を計算
- カメラ時計の「進み」「遅れ」「時刻どおり」を分・秒と総秒数で表示
- 設置場所、閲覧日、映像の抽出期間、立会人、補足情報を記録
- 保存した履歴の閲覧、編集、個別削除、全件削除
- 記録を1件ずつMarkdownファイルとして出力・再インポート
- 時刻に時間差を加算・減算できる独立した時間電卓
- 初回読み込み後のオフライン利用と、ホーム画面への追加

## 使い方

### カメラ時刻の誤差を計算・保存する

1. 端末の「日付と時刻」を自動設定にします。
2. 「計算」画面を開き、防犯カメラ映像の時計と端末時計を見比べます。
3. 比較したい瞬間に「タップで固定」を押します。
4. その瞬間にカメラへ表示されていた時刻を `HH:MM:SS` の24時間表記で入力します。
5. 「誤差を計算」を押します。
6. 必要に応じて、次の記録情報を入力します。
   - 防犯カメラ設置場所
   - 閲覧日
   - 映像の抽出開始・終了日時
   - 立会人の氏名・年齢
   - カメラ型番や確認状況などの補足
7. 「この記録を保存」を押します。

閲覧日には、基準時刻を固定した日が自動入力されます。抽出終了日を省略した場合は開始日と同日として扱います。終了時刻が開始時刻より前の場合は、日を跨いだものとして終了日が翌日に自動設定されます。

### 時間電卓を使う

「時間電卓」画面では、24時間表記の時刻に時間差を加算または減算できます。日を跨ぐ場合は「翌日」「前日」「N日後」「N日前」のように表示されます。

時間差は最大 `999:59:59` まで入力できます。この機能は保存済みの誤差記録とは連動しない、独立した計算ツールです。

### 履歴を管理する

「履歴」画面では、保存した記録が新しい順に表示されます。

- 記録をタップ: 設置場所、閲覧日、抽出期間、立会人、補足を編集
- 記録を左へスワイプ: 1件削除
- 「MD出力」: その記録をMarkdownファイルとして保存
- 「MDインポート」: Markdownファイルから記録を追加
- 「すべての履歴を削除」: 端末内の記録を全件削除

基準時刻、カメラ表示時刻、計算済みの誤差は履歴画面では編集できません。削除は取り消せないため、必要な記録は事前にMarkdown出力してください。

## Markdownによる記録の保管・移動

「MD出力」は、記録を `camsync_YYYYMMDD_HHMM.md` という名前のUTF-8テキストファイルとして1件ずつ保存します。出力には次の項目が含まれます。

- 記録日時
- 基準時刻
- カメラ表示時刻
- 誤差
- カメラ設置場所
- 閲覧日
- 抽出日・時間
- 立会人
- 補足

インポートできるファイルは1 MiBまでです。CamSyncが出力したMarkdownファイルの利用を推奨します。手作業で編集する場合は、`- **基準時刻:** 値` のようなラベルと書式を変更しないでください。

インポートは既存履歴へ記録を追加します。同じファイルを複数回読み込んだ場合の重複チェックはありません。また、現在は全履歴の一括バックアップではなく、1記録につき1ファイルの出力です。

## インストールとオフライン利用

CamSyncはインストール可能なPWAです。ブラウザのメニューから「インストール」または「ホーム画面に追加」を選んでください。iPhoneおよびiPadでは、Safariの共有メニューから「ホーム画面に追加」を選択できます。表示名はOSやブラウザによって異なります。

初回アクセス時は、アプリ本体を読み込みキャッシュするためにネットワーク接続が必要です。一度正常に読み込んだ後は、キャッシュを利用してオフラインでも起動できます。起動時やアプリを前面へ戻したときには、オンラインであれば新しいバージョンを確認します。

## データ保存とプライバシー

記録は、利用中のブラウザのIndexedDB（`CamSyncDB`）に保存されます。サーバーへの保存、アカウント連携、クラウド同期、分析は行わず、保存した記録を外部送信する処理もありません。

次の点に注意してください。

- データは同じブラウザ、同じブラウザプロファイル、同じサイト内でのみ利用できます。
- 別の端末やブラウザへ自動では同期されません。
- ブラウザのサイトデータやプロファイルの削除、端末の初期化などにより履歴が失われる可能性があります。
- Markdownファイルには設置場所、日時、立会人、補足などの機微な情報が含まれる場合があります。出力後のファイルも適切に管理してください。

重要な記録は、定期的にMarkdown出力して別の安全な場所へ保管することを推奨します。

## 計算仕様と注意事項

- 基準時刻には、CamSyncを開いている端末の時計を使用します。CamSync自体が時刻サーバーと同期したり、端末時計の正確性を検証したりする機能はありません。
- 端末時計が手動設定の場合、計算精度は保証されません。OSの「日付と時刻」は自動設定を推奨します。
- 誤差は基準時刻とカメラ表示時刻の24時間内の差から、日付境界を考慮して±12時間の範囲で算出します。12時間を超える実際のずれや、日数単位のずれを測定する用途には適していません。
- 本アプリは時刻差の計算と記録を補助するツールです。記録の正確性は、比較時の操作、端末時計、入力内容に依存します。

## ローカルで実行する

依存関係のインストールやビルドは不要です。

```sh
git clone https://github.com/yucchiz/camsync.git
cd camsync
python3 -m http.server 8000
```

ブラウザで [http://localhost:8000/](http://localhost:8000/) を開きます。IndexedDBとService Workerを本番に近い条件で動かすため、`index.html`を`file://`で直接開かず、HTTPで配信してください。

## 開発時の確認

静的チェック:

```sh
node --check sw.js
python3 -m json.tool manifest.json >/dev/null
git diff --check
```

自動テスト基盤はありません。変更時には、モバイル幅のブラウザで次の項目を確認してください。

- 誤差計算と日付境界付近の計算
- 保存、編集、削除、再読み込み後のIndexedDB永続化
- 現行形式のMarkdown出力と、旧形式・現行形式のインポート
- 初回読み込み後のオフライン起動とキャッシュ更新
- 保存記録から独立した時間電卓の計算

`sw.js`やキャッシュ対象を変更した場合は、`CACHE_NAME`を更新し、Service Workerを新しく登録した環境またはハードリロード後に確認してください。
